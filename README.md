# PesterMe
PesterMe is a mobile application developed in Flutter which finds free time in your calendar and prompts you to use it more effectively.

This software is still being actively developed and is in an early state. Most features are functional, but some work remains to be done.

## Implemented Features

- Create and manage multiple habits
- Device Calendar integration
- Specify frequency and duration of habits
- Prompt the user in advance to spend free time on planned habits
- Follow-up on habits when the user approves them
- Keeps a history of proposed habits that are completed, failed, or deferred

## Planned Features
- Keeps the user accountable by recording how free time is spent when not on planned habits
- Offers granular control over scheduling preferences per-habit
